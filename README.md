# Лабораторная работа №1

Выполнила Матренина Милана Павловна, группа: М8О-103БВ-26 

Проект представляет собой консольное приложение на Python, включающее калькулятор и конвертер единиц измерения.

## Функционал

### Калькулятор

Калькулятор поддерживает:
- целые и вещественные числа;
- арифметические операции `+`, `-`, `*`, `/`;
- операции `//` и `%`;
- унарные `+` и `-`;
- скобки;
- пробелы в выражении;
- обработку ошибок в выражениях;
- корректную работу с отрицательными операндами;
- сохранение успешных вычислений в историю.

### Конвертер

Конвертер поддерживает преобразование:
- единиц длины;
- единиц массы;
- температурных единиц.

Регистр единиц измерения не учитывается. Конвертация между разными группами единиц запрещена.

### Дополнительные возможности

- результаты успешных вычислений сохраняются в `history.json`;
- таблица единиц измерения и операторов загружается из `config.json`;
- вычисления выполняются с использованием Decimal, а итоговый результат округляется до 15 знаков после запятой;
- для вычисления арифметических выражений используется польская обратная запись и стек.

### Проверка унарных знаков

Для проверки корректности расположения операторов используются два состояния: `except_operand` и `flag`.

Флажок `except_operand` показывает, ожидается ли в текущей позиции операнд. Если его значение `True`, программа ожидает число, унарный знак `+` или `-` либо открывающую скобку. После чтения числа состояние меняется на ожидание оператора.

Флажок `flag` используется для контроля последовательности унарных знаков. Когда после бинарного оператора встречается `+` или `-`, такой знак может быть унарным, и `flag` устанавливается в `1`. После чтения числа флажок снова сбрасывается в `0`. Благодаря этому разрешаются конструкции `-5`, `2+-3` и `2++3`, но последовательности из нескольких унарных знаков, например `2+++3`, отклоняются.

Таким образом, программа с помощью этих двух состояний определяет, является `+` или `-` унарным или бинарным оператором, и одновременно контролирует правильное расположение операндов и операторов.

## Алгоритм вычисления

Для вычисления арифметических выражений используется польская обратная запись.

Сначала выражение разбивается на токены и проверяется на корректность. Затем с помощью стека операторов выражение преобразуется в польскую обратную запись с учётом приоритета операций и скобок.

После этого выражение вычисляется с помощью стека: числа помещаются в стек, а при встрече оператора из стека извлекаются необходимые операнды, выполняется операция, и результат возвращается в стек.

## Установка и запуск

Для работы программы требуется Python 3.13 и Poetry.

Клонировать репозиторий и перейти в папку проекта:

    git clone https://github.com/weiffii/lab01
    cd laba_01_py

Установить зависимости:

    poetry install


Для запуска калькулятора:

    python -m toolkit calc "выражение"

Для запуска конвертера:

    python -m toolkit convert число --from единица_измерения --to единица_измерения

Для просмотра справки:

    python -m toolkit --help

## Тестирование

Для запуска тестов:

    python -m pytest

Для проверки кода с помощью Ruff:

    ruff check .
