# Лабораторная работа №1

Выполнила Матренина Милана Павловна, группа: М8О-103БВ-26 

Проект представляет собой консольное приложение на Python, включающее калькулятор и конвертер единиц измерения.

## Возможности

### Калькулятор

Калькулятор поддерживает:
- целые и вещественные числа;
- арифметические операции `+`, `-`, `*`, `/`;
- операции `//` и `%`;
- унарные `+` и `-`;
- скобки;
- обработку ошибок в выражениях;
- преобразование выражения в обратную польскую запись;
- вычисление выражения с использованием стека;
- округление результата до пятнадцати знаков после запятой;
- сохранение успешных вычислений в историю.

### Конвертер

Конвертер поддерживает преобразование:
- единиц длины;
- единиц массы;
- температурных единиц.

Таблицы преобразований загружаются из конфигурационного файла `config.json`.

Результаты успешных преобразований также сохраняются в историю.

## Запуск проекта

Для запуска калькулятора:

    python -m toolkit calc "выражение"

Для запуска конвертера:

    python -m toolkit convert число --from единица_измерения --to единица_измерения

Для просмотра справки:

    python -m toolkit --help

## Тестирование

Для запуска тестов:

    python -m pytest

Для проверки кода с помощью Ruff:

    ruff check .
